# Security policy

Maktab stores children's records and school money. Please report vulnerabilities privately.

Use GitHub's **private vulnerability reporting** on this repository: open the **Security** tab and
choose **Report a vulnerability**. Do not open a public issue for security problems.

Include what you found, how to reproduce it, and the impact you expect. We aim to acknowledge
within 72 hours and to agree a disclosure date with you.

Supported versions: only the latest release (pre-1.0: the `main` branch).
